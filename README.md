# Environment variables

Configure these in the Vercel project (Environment Variables), or locally via `.env.local` (see `.env.example`):

| Variable | Purpose |
|----------|---------|
| `NEXT_PUBLIC_ADSENSE_ENABLED` | `true` to enable AdSense; anything else keeps ads off |
| `NEXT_PUBLIC_ADSENSE_CLIENT` | Publisher client id (e.g. `ca-pub-…`) |
| `ADS_TXT_CONTENT` | Full body served at `/ads.txt` |
